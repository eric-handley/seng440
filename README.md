# seng440



## How to use this repo
Make sure there is a sample in /samples, currently we reference samples_1.wav by default in the make file, but you can use any other
type '''make''' in the command line. 
the new file will be '''/build/(de)compressed.wav'''
Alternatively, you can use -i \<input file path\>
